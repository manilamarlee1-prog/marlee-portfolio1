MARLEE'S ITE 1 PORTFOLIO PROJECT

HOW TO OPEN IN SPCK EDITOR
1. Extract the ZIP file on your phone.
2. In Spck Editor, open/import the extracted MarleePortfolio folder as a project.
3. Keep index.html, style.css, script.js, and the images folder together.
4. Open index.html and tap Run/Preview.

PROJECT FILES
- index.html: page structure
- style.css: styling and responsive layout
- script.js: interactive features
- images/profile.jpg: profile photo (first image you sent)
- images/project-*.jpg: the six project screenshots you sent

BEFORE SUBMITTING
- Check your displayed name and course details.
- Replace the contact placeholders with your real email and phone number.
- Confirm that the six project screenshots represent activities you completed and adjust their titles if needed.

FEATURES
- Home, About Me, Skills, Projects, Contact, Footer
- External CSS and JavaScript
- Responsive mobile navigation
- Dark/light mode
- Welcome message
- Read More / Show Less
- Live date/time and copyright year
- Back-to-top button
- Six image project cards
